## 👨‍💻 About Me

I'm a **Frontend Developer** passionate about building **interactive, responsive and user-friendly web interfaces**. I love turning ideas into real products that connect code with everyday life — and shipping them live on **Vercel**.

- 🔭 Currently **optimizing my personal projects** and building dynamic web apps with **Next.js** and **React**
- 🌱 Learning **advanced TypeScript**, **Next.js** features and **scalable software architectures**
- 🧪 Exploring frontend testing best practices with **Jest** & **Vitest**, plus advanced **deployment workflows**
- 🎨 Focused on **Mobile First** design, **Tailwind CSS**, smooth **GSAP** animations and responsive layouts
- 👯 Open to collaborate on **open-source frontend**, **React** and **Next.js** projects
- ⚡ Fun fact: I built **[MoodBeats](https://github.com/Moroni-Capcha/moodbeats)**, a playlist generator based on your mood 🎧
- 📫 Reach me at **raulmoronicapchacadillo@gmail.com**
